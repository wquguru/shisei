> 状态：**计划，未开工，待 D-12**。按 AGENTS §8，新增图片系列要人点头；拍板前只写清单和提示词，不生成、不入库、不改 verify。
> 做法沿用服装库（[costume/PLAN.md](../costume/PLAN.md)）：清单 → 卡片 → 试验 → 一套一套生成 → QC → 入库。

## 1. 定位

给姿势和服装配的背景：空场景，中央留一块空地，以后把人台或角色合成进去。
差异化：**三个机位高度和姿势库对齐**（平视、俯视、仰视），同一个地方三张图透视一致，合成时人和背景的透视对得上；
参考站的服装和姿势都没有背景。CC0、四语、和姿势库同一个站。

## 2. 画面格式

| 项 | 定法 | 理由 |
|---|---|---|
| 呈现 | 写实照片，空无一人 | 背景要能直接用；有人就没法合成 |
| 视角 | `eye` 平视 1.6 m 水平、`above` 3.5 m 下俯 30°、`below` 0.4 m 上仰 35° | 姿势库 front / diag / side 都是平视，above 约 30°，below 约 45°（GENERATION.md）；场景不用转方向，只换高度 |
| 合成位 | 画面中央、离镜头约 4 m 的空地 | 三张图都留着，合成的人站在那里 |
| 镜头 | 35 mm、全景深 | 背景清楚，透视适中 |
| 比例 | 3:4 竖版 | 和姿势、服装一致 |
| 一件 = | 一个地方 × 一个光线（时段 / 天气 / 季节） | 同一个客厅的白天和夜晚是两件，各三张 |

## 3. 提示词

模板都在 `tools/series_kit.py`（`SCENE_FRONT` / `SCENE_TURN`），简报由 `tools/series_brief.py scene` 拼好。

- **平视（文生图）**：`Photograph of {desc}. An empty location with nobody in it, {eye 视角}, 35 mm lens, deep focus, {空地}. {light}. …`
  再接大类的 rules / negatives 和全库负面词（无人、无可读文字、无 logo、无车牌、无真实地标）。
- **俯视 / 仰视**：以平视为参考，“同一个地方、同一个朝向、同一时刻”，`keep` 逐条列出必须不变的东西；只允许多露出地面（俯视）或天花板、天空（仰视）。
- **desc 写法**：地方类型 + 墙 / 地面材质 → 主要家具或景物**按位置写**（远墙、左墙、右边缘）→ 窗或光源在哪 → 最后一句写中央空地。
  位置写清楚是为了三个高度对得上；家具一律靠边，空地不放东西。
- **light**：每个变体一句，写光从哪来、什么色温、什么时段。和光线库（[light/PLAN.md](../light/PLAN.md)）同一套说法，以后变体可以直接引用光线预设。

## 5. 全库禁区

- 不出现人、人影、雕像、人台、动物；镜子和玻璃里也不能有人。
- 不出现可读文字：招牌、菜单、海报、路牌、车牌、屏幕都只能是空白或纯色。
- 不做真实地标、可认出的天际线、连锁店的店面设计、航司和交通运营商标识。
- 不做教室和学校（和姿势库组合时有未成年联想）；不做病床和医疗场面。
- 不做宗教场所（寺庙、神社、教堂、祭坛、宗教雕像）。
- 原创幻想场景不像任何游戏、动画、电影里的地点。

## 6. QC（开工前补 `docs/qc/scene_prompt.md`）

每件一张审图（平视 / 俯视 / 仰视三格）：
1. **content**：有人、人影、动物、可读文字、logo、车牌、真实地标、宗教元素。
2. **spot**：中央空地被占了（家具、车、植物、光效）。
3. **view**：高度不对（俯视没看到更多地面、仰视没看到更多天花板 / 天空、平视地平线明显不在中间、竖线歪）。
4. **consistency**：三张不是同一个地方 / 同一朝向 / 同一时刻（窗换了边、家具变了、白天变夜晚）。
5. **form**：和“要点”不符（历史类按形制逐条审）。
场景不抠图，没有 matte 项。

## 7. 流程

1. `python3 -I tools/series_cards.py scene` 展开卡片到 `data/scenes.json`（ID `E001…`，稳定不复用）。
2. 试验：`python3 -I tools/series_brief.py scene --probe ~/Downloads/scene-probe01`（每类 2–3 件最难的，共 23 件 69 张）。
   看通过率和翻车点，改模板。
3. 正式：每类一份简报 `series_brief.py scene <CAT> ~/Downloads/scene-<CAT>-run01`，前 10 件自检闸（平视通过 < 7 就停）。
4. 收图、审图、入库的工具等 D-12 拍板后再写（照 `costume_intake.py` / `costume_sheets.py` / `costume_qc.py`，去掉抠图）。

## 8. 待试验验证的风险

- **空地**：模型爱在中央放椅子、地毯、路人；desc 和要点都写了“空着”，试验看守不守得住。
- **俯视 / 仰视的一致性**：仰视露出的天花板、天空是新画的，最容易漂；室内窗的位置是检查重点。
- **招牌和屏幕没字**：港式街道、霓虹街、地铁站最难，放进了试验。
- **影棚仰视**：可能露出背景纸上沿或灯架；ST 的 keep 写了不准露。
