# 道具库计划（草案，2026-10-30）

> 状态：**计划，未开工，待 D-13**。按 AGENTS §8 要人点头；拍板前只写清单和提示词。
> 做法沿用服装库配饰 AC（悬浮商品照），流水线（抠图、换底、四视角、审图）几乎全部复用。

## 1. 定位

角色手里拿的、身边放的、身下坐的东西：手机、伞、乐器、茶具、椅子、沙发。和姿势库直接相关的是**家具与坐具**——
坐姿、倚靠、躺姿都需要一件道具，所以 FN 写得最细（座高按厘米写）。帽子和包已经在服装库 AC 里，这里不重复。

## 2. 画面格式

| 项 | 定法 |
|---|---|
| 呈现 | 商品照：一件东西，没有手、没有人、没有展示架；自带的支架（三脚架、球座）算物件本身 |
| 摆放 | `float` 悬浮（手持物，按自然朝向）/ `stand` 落地（家具、食物等立在看不见的水平面上，不画地板） |
| 大小 | `S` 约占画面高 50% / `M` 65% / `L` 80% |
| 视角 | `front` / `back` / `side` / `diag`，和服装库一样（D-10） |
| 背景 | 浅灰；白色和很浅的物件用中灰；入库时抠图合成到统一 `#D9D9D9`，另出透明版 |
| 一件 = | 一个物件 × 一种颜色 / 材质 |

## 3. 提示词

模板在 `tools/series_kit.py`（`PROP_FRONT` / `PROP_TURN`），简报 `tools/series_brief.py prop`。
- **正面**：`Product photograph of {desc}, a single object {place}, straight front view, … filling {fill} of the frame height …`
- **背面 / 侧面 / 斜侧**：同服装库的转视角，`keep` 列不变项；背面加一句“背面是真背面、不是镜像，正面才有的屏幕、表盘、装饰不延续到背面”。
- **desc 写法**：品类 + 形状 → 颜色材质 → 关键结构**带数量**（几根弦、几个键、几条腿）→ 状态（开 / 合、点亮 / 熄灭）；
  模型爱加的东西用否定句（表盘没有字母、球上没有印字）。

## 5. 全库禁区

- **武器一律不做**：刀剑、枪、弓、棍棒、法杖、魔杖；高尔夫球杆这类像武器的也不做。
- 不做烟、电子烟、药品、钱币；酒只做无标签的瓶和杯。
- 不做品牌相似款：手机摄像头排布、游戏手柄造型、吉他琴头、名牌家具。
- 不做宗教器物（香炉、佛珠、十字架）、骷髅、神秘学符号；文房用品上不写字、不盖印。

## 7. 流程

1. `python3 -I tools/series_cards.py prop` → `data/props.json`（ID `T001…`）。
2. 试验：`series_brief.py prop --probe ~/Downloads/prop-probe01`（每类 2–3 件最难的）。
3. 正式：每类一份简报，前 10 件自检闸。
4. 收图沿用 `costume_intake.py` 的抠图换底（改成读 `props.json`），等 D-13。

## 8. 待试验验证的风险

- **数量**：弦、品、徽、键、辐条，模型最容易多或少；乐器和自行车放进了试验。
- **无字**：表盘、指南针、地球仪、书页，模型爱补字母；放进了试验。
- **透明物**：玻璃杯、沙漏、水晶球抠图会带底色，和服装库薄纱同样处理（QC 标出，透明版注明）。
- **长物件的“正面”**：自行车、滑板、望远镜，卡片里写明了朝向。
