# 动物库计划（草案，2026-10-30）

> 状态：**计划，未开工，待 D-14**。按 AGENTS §8 要人点头。和场景、道具不同，动物库的画风还没定，
> 所以现在只写了大类、试验卡和试验简报；完整动作清单等试验定了画风再写，免得卡片白写。

## 1. 定位

宠物和动物的姿势参考：“把我家猫摆成这个姿势”。参考站完全没有动物。和姿势库同一套五个机位，
以后可以做人 + 宠物的互动组合（抱猫、遛狗、骑马），像双人系列一样。

## 2. 画风（D-14 要定的事）

| | A：关节素体线稿（推荐） | B：写实照片 |
|---|---|---|
| 和姿势库 | 同一种画法，放在一起是一套 | 风格不同 |
| 一张卡覆盖 | 所有品种、毛色（只管结构） | 要按毛色、品种分开 |
| 姿势读得清 | 线条只表达结构，关节、腿的前后一眼可见 | 毛会把关节和腿的走向盖住 |
| 风险 | 动物“素体”模型没见过多少，可能画成玩具 | 毛色、品种发散；更像图库照片 |

推荐 A，B 只在试验里画正面作对照，用数据定。

## 3. 组织方式：物种 × 动作，不穷举品种

- **物种**按体型结构分：猫；狗（小 / 中 / 大三种体型，不认具体品种）；小型宠物（兔、仓鼠）；马与家畜；鸟；野生；幻想生物。
- **动作**用一套通用词表：站、坐、趴（狮身人面式）、侧卧、团睡、走、奔跑（腾空相）、跳、伸懒腰、回头、舔爪、仰躺露肚、扬蹄（马）。
- 一件 = 一个物种的一个动作，五个机位。

## 4. 提示词

模板在 `tools/series_kit.py`（`ANIMAL_LINE` / `ANIMAL_PHOTO` / `ANIMAL_TURN` / `ANIMAL_VIEW_TEXT`）。
- **A 线稿**：`Clean black-line construction drawing for a pose reference: a smooth featureless wooden artist's mannequin of an adult {species}, … ball joints at the shoulders, elbows, wrists, hips, knees and hocks, a segmented neck and {tail}, no fur, no eyes … Pose: {desc}. {view}. …`
  画风沿用 Muse 的 `pose_lineart_gallery` 定稿线稿（线宽、留白），只换素体。
- **B 照片**：同一句 Pose，加 `{coat}`，浅灰底。
- **转机位**：以 A 正面为参考，“同一只动物、同一个姿势，只有相机动，不要镜像”。五个机位的写法对齐姿势库：俯视约 30° 看到头顶和整条背，仰视约 45° 看到下颌、胸腹底面、近处爪子比头大。
- **desc 写法**：整体姿态 → 前腿 → 后腿 → 尾巴 → 头和耳朵，每个部位写位置；会被画错的写成否定句。

## 5. 禁区

不画幼崽；不画捕猎、猎物、血、受伤、屠宰；不画项圈、牵引绳、鞍具、笼子；幻想生物不像任何作品里的角色，不带宗教图像；
人和动物同框只做日常互动，不和性感系列组合。

## 6. QC（开工前补 `docs/qc/animal_prompt.md`，以 limbs_prompt.md 为底）

肢体计数扩展到四足、尾、翅、耳、角；关节方向（猫狗后腿跗关节向后弯、马前膝向前弯）；五机位是同一个姿势；视角对不对；内容禁区。

## 7. 试验（animal-probe01）

10 个动作，覆盖六类里最难的：猫端坐 / 伸懒腰 / 团睡，中型犬坐 / 腾空奔跑，大型犬趴，兔直立，马扬蹄，乌鸦展翅，中国龙盘曲。
A 画全部五个机位（50 张），B 只画正面（10 张），共 60 张：
`python3 -I tools/series_brief.py animal --probe ~/Downloads/animal-probe01`

看三件事：A 能不能稳定画成“关节素体”而不是卡通或真毛；腿和尾巴的数量、关节方向；五机位是不是同一个姿势。
通过后在 D-14 定画风，再按第 3 节写全部动作卡。
