# 光线库计划（草案，2026-10-30）

> 状态：**计划，未开工，待 D-15**。按 AGENTS §8 要人点头；拍板前只写清单和提示词。

## 1. 为什么单独成一类

光有四个维度：**光源**（自然 / 人工）、**时段**（黎明 → 正午 → 黄金时刻 → 蓝调 → 夜）、**空间**（窗、树荫、门洞、隧道）、
**位置**（顺光、侧光、伦勃朗、轮廓、顶光、底光、剪影）。它们不是物件，是一切画面的属性：
同一个姿势、同一件衣服，换个光就是另一张图；AI 出图里光写得含糊是最常见的“不像参考”的原因。

如果只把光写进场景变体（白天 / 夜晚），四个维度只能覆盖时段一项，而且被场景绑死。所以拆成两层：
1. **光线预设库（L###）**：每个预设是一句定稿的光线描述，配一组参考图，图里**主体永远不变**，只有光变。
2. **复用**：场景卡的 `light`、以后的组合器（姿势 + 服装 + 场景 + 光线）都引用这套预设的说法，不各写各的。

不做全排列（四个维度相乘上千种），按摄影里真正常用、能一眼看出差别的组合挑 55 个。

## 2. 画面格式

| 项 | 定法 | 理由 |
|---|---|---|
| 主体（TD SN AR FX） | 姿势库同款无脸浅灰人台，自然站立；25 cm 灰球放在髋高的细柱上，位于人台右前方各一米（三个机位都看得到） | 人台看光在身体上怎么走；灰球是摄影里读光的标准件，高光位置、明暗交界软硬、投影方向一眼可见 |
| 主体（PO） | 浅灰石膏头肩像：只有额头、眉弓、浅眼窝、鼻梁、颧骨、下颌的大块面，没有眼睛、眉毛、嘴、头发；15 cm 灰球在它右前方各 40 cm、肩高；胸像近景，85 mm、1.8 m | 人像光位靠鼻影和脸颊区分（环形光的小环、伦勃朗的三角、蝴蝶光的对称蝶影），蛋头没有鼻子、全身远景里头也太小，画不出来。石膏像不是真人，和人台一样中性 |
| 写法 | 写实照片 | 光的质感（软硬、色温、衰减）线稿表达不了 |
| 视角 | `front` / `diag` / `side`，都平视 | **灯不动、相机绕人台转**：同一束光从正面、斜侧、侧面看分别什么样，这是线稿姿势库对应的三个平视机位 |
| 环境 | 只给解释光所需的最少环境：时段类是空旷水泥广场，空间类是白墙空房、树荫、门洞，光位类是中灰无缝背景 | 环境多了就变成场景库 |
| 方向写法 | 按正面机位的画面左右写（from image-left） | 服装库的经验：画面坐标比“人物的右边”稳 |

## 3. 提示词

模板在 `tools/series_kit.py`（`LIGHT_SUBJECTS` / `LIGHT_FRONT` / `LIGHT_TURN`），简报 `tools/series_brief.py light`。
主体按大类定：`_categories.json` 里 PO 写了 `"subject": "bust"`，其余默认 `figure`；简报按主体分别给模板。

正面：
```
Lighting reference photograph: {主体：无脸人台 + 灰球}, {setting}. Lighting: {desc}. {front 视角}.
Whole figure and sphere in frame, deep focus, true-to-life exposure with no added grading, 3:4 vertical.
The light must read clearly on the mannequin and the sphere: which side is lit, where the highlight sits on the
sphere, how soft the shadow edge is and which way the cast shadow falls.
{rules} No people, no real face, no hair, no clothing, no text, no logo, no watermark. {negatives}
```
转视角：以正面为参考，“灯、人台、灰球、环境都不动，只有相机移动，所以亮面、高光、影子出现在新角度下该在的位置；不要镜像”。

**desc 写法**（每个预设一句，也是对外复用的那句）：光源 → 方向（画面左右 + 高度角）→ 软硬 → 色温（K）→ 影子落向 → 阴影面怎样（有无补光）。
例：`one key light 45 degrees to image-left and 45 degrees above, no fill, the image-right side of the head in shadow except a small lit triangle on the cheek plane …`

## 5. 禁区

人台无脸、无发、无衣服，不能变成真人；石膏胸像只有块面，不能长出眼睛、眉毛、嘴唇、头发、皮肤质感，也不能像任何真人；
不出现文字、logo；霓虹管、屏幕没有字；光效要物理上说得通，不做魔法光。

## 6. QC（开工前补 `docs/qc/light_prompt.md`）

每件一张审图（正面 / 斜侧 / 侧面）：
1. **content**：人台变成真人、有脸或头发、穿衣服；胸像长出五官、头发或像真人；出现文字。
2. **subject**：主体变了（姿势、灰球位置、人台比例；PO 的胸像换了头型或景别）。
3. **light**：和 desc 不符——看灰球的高光位置、明暗交界软硬、投影方向；色温明显不对。
4. **turn**：转视角后光“跟着相机走”了（三张亮面都在画面同一侧），或者是正面的镜像。

## 7. 流程

1. `python3 -I tools/series_cards.py light` → `data/lights.json`（ID `L001…`）。
2. 试验：`series_brief.py light --probe ~/Downloads/light-probe01`（13 件，覆盖五类里最难的：环形、伦勃朗、分割三个胸像光位，百叶、树荫、黄金逆光、正午、路灯……）。
3. 正式：每类一份简报。
4. 通过后：场景卡的 `light` 改成引用预设（`"light": "@TD:golden-front"` 这类写法，`series_cards.py` 展开时替换成预设的 desc），组合器多一个“光线”下拉。

## 8. 最大的风险

**转视角时光跟着相机走**：模型倾向于让每张图的亮面都在画面同一侧。模板写了“灯不动、只有相机动”，
试验里看 diag / side 的通过率；守不住就退成只出正面一张（光线参考本来主要看正面）。

**胸像长出五官**：模型容易把石膏像补成有眼有嘴的雕像或真人。模板写了只有块面、负面词列了眼睛、眉毛、嘴唇、头发；
试验里看三个胸像光位守不守得住，守不住就把眼窝也写成平的（鼻影和脸颊阴影仍然读得出）。
