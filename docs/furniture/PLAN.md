# 家具库计划（草案，2026-10-30）

> 状态：**计划，未开工，待 D-16**。按 AGENTS §8 要人点头；拍板前只写清单和提示词。
> 原先是道具库里的一类（FN 家具与坐具），因为和姿势库的关系不同，单独拆成一个库。

## 1. 为什么单独成库

道具是“拿在手里”的，家具是“压在人身下”的：坐姿、躺姿、倚靠、手撑台面都离不开它。合成时有三件道具库不管的事：
1. **高度要对**：人坐上去，屁股要落在座面上，所以每件都记真实尺寸（`dims`，厘米），座高单独记 `seat`。
2. **要看到台面**：姿势库有俯视机位，人坐在椅子上从上往下看，椅子也得有同角度的图，所以多一个 `above`。
3. **比例统一**：入库时按 `dims` 把每件缩放到同一个 px/cm，任意两件家具、家具和人台放在一起大小都对。

另外加一类参考站和别家都没有的东西：**影棚造型台与结构件**（苹果箱、台阶块、矮墙、门框、栏杆），
拍人像时模特就是靠它们摆出坐、踩、倚的姿势。

## 2. 画面格式

| 项 | 定法 |
|---|---|
| 呈现 | 商品照：一件家具立在看不见的水平地面上，不画地板、墙、地毯，没有别的家具和摆件 |
| 视角 | `front` / `back` / `side` / `diag` + `above`（约 30° 俯视，从左前上方，和姿势库 above 对齐） |
| 尺寸 | 卡片写 `dims {w, d, h, seat}`，正面提示词直接写真实尺寸；入库按尺寸统一缩放 |
| 背景 | 浅灰；白色、浅色家具用中灰；抠图合成到 `#D9D9D9`，另出透明版（和服装、道具同一流水线） |
| 一件 = | 一个款式 × 一种木色 / 面料 |

## 3. 提示词

模板在 `tools/series_kit.py`（`FURN_FRONT` / `FURN_TURN` / `FURN_VIEW_TEXT`），简报 `tools/series_brief.py furniture`。

正面：
```
Product photograph of {desc}, real size about {w} cm wide, {d} cm deep and {h} cm high, a single piece of furniture
standing on an invisible level floor with its feet or base on a flat line and no visible floor, straight front view,
camera level with the middle of the piece, centered, … visible joinery, upholstery seams and hardware, 3:4 vertical,
catalogue style. {rules} No person, no mannequin, no floor, no rug, no wall, … no other furniture, no objects on or
around it unless stated, no text, no logo … {negatives}
```
转视角（背面 → 侧面 → 斜侧 → 俯视）：以前面的视角为参考，`keep` 列不变项，并强调“腿、横枨、靠背条、坐垫的数量和真实尺寸不变”；
背面要求真背面（软包看背板、框架看榫卯背面），俯视要看清座面 / 桌面 / 床面。

**desc 写法**：品类 + 形状 → 材料颜色 → 结构**带数量**（几条腿、几根靠背条、几个抽屉、几个坐垫）→ 座高 / 台面高 → 状态（门关着、台面空着）。

## 5. 禁区

- 不做设计师名作复刻（Eames、Barcelona、Egg 等）和品牌标识；中式不刻字、不盖印。
- 不做儿童家具（上下铺、婴儿床、儿童椅）：和姿势库组合时有未成年联想。
- 不做宗教家具（供桌、香几、祭坛、跪凳）、王室和国家徽记。
- 镜子只反射纯灰；书架上的书没有可读书脊。

## 6. QC（开工前补 `docs/qc/furniture_prompt.md`，以 costume_prompt.md 为底）

状态：`content`（人、地板墙面、多余家具摆件、文字、名作复刻）→ `matte` → `view`（俯视没看到台面、背面是镜像）→
`consistency`（五张之间腿数、条数、坐垫数、颜色变了）→ `form`（要点，尤其是数量和中式结构）→ `scale`（比例明显不对：座高、台面高和 dims 差太多）。

## 7. 流程

1. `python3 -I tools/series_cards.py furniture` → `data/furniture.json`（ID `F001…`；`series_cards.py` 检查每件都有 dims）。
2. 试验：`series_brief.py furniture --probe ~/Downloads/furniture-probe01`，每类 1–2 件最难的，共 19 件 95 张（四柱床、摇椅、玻璃柜、架子床、台阶块、窗框……）。
3. 正式：每类一份简报，前 10 件自检闸。
4. 收图：沿用 `costume_intake.py` 抠图换底，再加一步按 `dims.h` 统一缩放到同一 px/cm；等 D-16。

## 8. 待试验验证的风险

- **俯视机位**：服装库没试过 30° 俯视转视角，模型可能画成正顶视或者干脆不转。
- **数量一致**：靠背条、抽屉、腿在五张之间最容易变。
- **尺寸**：模型对“45 cm 座高”没有概念，主要靠入库缩放兜底；`scale` 只拦明显不对的（吧凳画成矮凳）。
- **“没有地板”**：落地家具最爱自带一块地面和投影；抠图能去掉投影，但地板要重画。
