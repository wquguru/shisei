# 画廊设计

给 agent 实现 `web/` 用的文字版。视觉稿在设计画布（Shisei Pose Gallery，五块画板：桌面、Logo、灯箱、手机、卡片状态），
尺寸、颜色、文案以画布为准，这里只记规则。

## 风格
- 底色 `#F5F2ED` 暖米白，次级面 `#ECE7DF`，描边 `#DCD6CC`；文字 `#18181B` / `#3F3D39` / `#55534E`，最浅的说明文字 `#6B6862`。
- 主按钮黑色胶囊 `#18181B`，次按钮米白描边胶囊；强调胶囊（图包大小、灯箱计数、更新日志 new 标签）用 `#F2F08A` 黄色。
- 标题 Inter Tight 800，字距 -0.05em，带 3px 4px 的暖色投影 `#EDB79C`；中文 Noto Sans SC；编号和计数 JetBrains Mono。
- 网格卡片统一暖灰底 `#ECE7DF`；悬停或聚焦时底色过渡成该分类色、上浮 3px 并加阴影（0.25s）。手机没有悬停，保持暖灰。
- 首屏滚动方块始终用分类色。线稿用 `mix-blend-mode: multiply` 叠上去，白底自动变成底色。分类色：
  坐姿 `#D3D1E6` 站立 `#AFC3E0` 跪姿 `#BCD3C6` 躺姿 `#E3CBB0` 侧坐 `#EBC0BC` 蹲姿 `#C7DCD6` 前倾 `#E6B7A1` 后仰 `#CBD0AC` 扭转 `#DDB9C8`；
  实拍统一 `#E4E1DC`。
- 卡片圆角 28px（手机 22px），灯箱外框 34px。

## 页面结构（桌面）
1. 导航：logo 胶囊、姿势 / 分类 ▾ / 机位 ▾ / 实拍 / 使用方法 / 更新日志，右侧语言菜单（地球图标 + 当前语言名 ▾）、深色模式、GitHub。不做搜索（2026-10-29 去掉）。
2. 首屏：大标题（中文「姿势参考 · 五机位」，2026-10-31：站上有五种格式，标题不点名其中一种；「线稿」留在说明句和网页标题里。「白模」只指白模格式，素体线稿叫素体）、一句说明（提到三种新格式）、两行反向滚动的姿势方块（尊重 `prefers-reduced-motion`）、各系列套数胶囊、「浏览 N 套姿势」「下载图包 [大小]」、适用工具。
   N 是全部已发布的套数（有通过质检的机位），不随性感内容开关变化；没有写死的数字。
3. 全部姿势：吸顶筛选条（分类胶囊带色点和数量、机位、线稿/实拍、按姿势/逐张、计数），下面是网格。
4. 页脚：只写一句「全部素材由 Shisei 自制。」加链接，不提其他项目。

## 性能（2026-11-01）
- 字体：只自托管 Inter Tight（可变字重）和 JetBrains Mono 500 的拉丁子集，共约 65 KB，`font-display: swap`，HTML 里预加载 Inter Tight；
  中文 / 日文 / 韩文按页面语言用系统字体（苹方、冬青黑体、雅黑；Hiragino Sans、游ゴシック；Apple SD Gothic Neo、Malgun Gothic）。
  之前从 Google Fonts 加载，首页 28 个请求、1.6 MB，且 fonts.googleapis.com 在中国大陆常连不上、会卡住首屏。
- 首屏滚动方块：第一行前 8 张立即加载，其余（含无缝循环的复制段和手机上隐藏的第二行）`loading="lazy"`，滚到附近才取。
- 网格卡片 `content-visibility: auto`：屏外的卡不排版、不绘制；卡片四周留 24 px 内边距（负外边距抵消），悬停阴影和焦点框不被裁掉，手机上不留。
- 没做的：目录 JSON 仍内联在页面里（拆出去会让网格多等一个请求，gzip 后只有约 37 KB）；AVIF 档位待试几张确认收益后再定。

## 交互
- 姿势卡：默认正面；悬停、聚焦或点按圆点切换本卡机位；顶栏选机位时全部卡片统一切换。
- 缺机位（2026-10-29 改）：圆点变空心并禁用。主图位置不画虚线框，放一个图标（线稿铅笔、实拍相机）、一句短话和一个出口：
  卡片上是「看<最近的有图机位>」（同一素材内，素材切换是全页的）；手机三列只留图标和「补画中 / 无实拍」。
  灯箱缺图时先给另一种素材的同机位（「看线稿」/「看实拍」），再给最近机位；对比里缺的一边只有图标和标题。
- 实拍模式只列有实拍的 23 套；某机位无实拍时同样按缺机位处理（P050 只有正面）。
- 逐张视图：每个机位一张小卡，受分类和机位筛选影响。
- 灯箱：左边大图，右边四语名称、机位缩略图、素材切换、可复制的 `desc_en`、下载 900 图、复制 ID、全尺寸包链接。
  键盘 ← → 换机位、↑ ↓ 换姿势、L 在这套有的素材之间轮换、Esc 关闭；手机左右滑动。
- 白模、深度、法线（2026-10-31）：列表照旧只看线稿，不加筛选（挑姿势靠认形，线稿最清楚；三种新图底色灰、黑、紫，铺满一屏很重）。
  新格式只出现在三处：首屏滚动方块隔一个换成三种图之一（左下角黑色小标签写格式名；2026-11-01 起点任一方块打开这套的大图，落在方块的机位和格式上，悬停时整行暂停、方块微微上浮；滚动行保持 aria-hidden、不进 Tab 顺序，键盘和读屏走下面的网格）；灯箱素材切换扩成
  「线稿 · 白模 · 深度 · 法线 · 实拍 · 对比」，这套没有 maps 时不显示三个新按钮，选中新格式时切换下面一句说明（白模可直接当参考图，
  深度 / 法线给 ControlNet、会带上人台体型；不写没验证过的效果）；下载面板加「其他格式」两行。
  新格式和线稿逐像素对齐，所以大图底部有「对照线稿」滑杆：线稿从左边擦进来，multiply 叠在图上，方便看合不合。
  滑杆的指针事件不传给大图，避免拖动时触发左右滑换机位。下载文件名加 `_clay` / `_depth` / `_normal`，深链 `#P001-diag-clay`。
- 灯箱默认总览（2026-11-01，方案 B1，取代原「对比」）：点卡片打开大图，先看到这个机位的全部格式。桌面：线稿、白模、深度、法线排成 2×2，
  实拍单独一列；手机（方案 M1）：三列，第一行线稿、白模，第二行深度、法线，实拍占满第三列两行高，五张一屏。这套没有三种新格式时只有
  线稿一格（加实拍）。某机位缺某种格式时那一格留位置、显示缺图图标，网格不因换机位而错位。只有线稿的套直接打开线稿。
  点任意一格放大成单张；放大后图下方一排格式（方案 X1）：「全部」+ 这套有的格式，每格一张当前机位的小图，点一下直接换，「全部」回总览，
  取代原来的「← 全部格式」按钮。白模 / 深度 / 法线带「对照线稿」滑杆，滑杆在图和格式排之间单独一条。手机上在大图上下滑也按这排的顺序换格式
  （左右滑仍是换机位），换完在图中间闪一下格式名；「详情」展开时不响应上下滑。Esc 先回总览、再按一次才关闭；从总览进入单张会推一条浏览历史，
  浏览器后退 / 手机返回手势也先回总览，关闭时收回这条历史。总览的下载按钮下载线稿，其他格式在放大后下载。
  深链：`#P001`、`#P001-diag` 是总览（旧的 `-compare` 也落到总览），`-line` / `-clay` / `-depth` / `-normal` / `-photo` 是单张。
  网格卡片和首屏滚动方块都打开总览（实拍模式下打开实拍）；从滚动方块进来时，方块那一种格式的格子描黑边、名字加粗，不加文字标签。
  手机总览隐藏左右箭头。手机灯箱高度是 100dvh：浏览器地址栏露出时会矮约 180 px，所以手机上标题上方只留「ID · 分类」，机位缩略条压到 44 px 高，
  格式说明收进「详情」，让图在首次打开时就有足够高度（之前要滑一下、地址栏收起才正常）。
  加载顺序（2026-11-01 改）：眼前的图（总览格子、大图）高优先级先取；它们全部加载完（最多等 4 秒）才开始预取，预取排一条队、同时最多 2 个，
  换机位 / 格式 / 套时丢掉还没开始的。手机上队列最前面是保存按钮要用的文件，其后依次是：总览其他四个机位的格子（w300 / w600 由 srcset 按屏幕选）、
  单张时同格式的其他机位和这个机位的其他格式（w900）、下一套的同一机位。省流量模式和 2G 只取保存按钮的文件。
  换机位不再整段重写：总览、机位缩略条、格式排只改有变化的节点；换图时新图在后台解码完再替换，替换前旧图半透明，不出现空白闪烁；加载失败的图显示「重试」。
  手机保存（2026-11-01）：总览的按钮叫「保存这个机位」，一次把这个机位的全部格式（线稿、白模、深度、法线、实拍，有几张算几张）交给系统分享面板，
  iOS 上是「存储 N 张图像」，一次进相册；文件在点之前就预取好（share() 必须在点击手势里调用），没取完时提示「正在准备」。放大单张时按钮是
  「保存白模」这类，只存这一张。不能分享文件的浏览器（微信等）按钮叫「怎么保存？」，点了提示放大后长按保存。桌面不变：一次下载一个文件。
- 手机：默认三列网格（只留 ID + 名称一行、不显示圆点），右侧按钮切回两列，选择记在 localStorage。没有筛选面板（2026-10-29 去掉）：
  吸顶条里系列行随页面滚走，分类胶囊和机位 / 素材 / 视图开关留在顶部，各行横滑不换行。
- 手机首屏：连导航一屏放下（标题 32px、滚动方块只留一行、胶囊缩小），首屏底部露出「全部姿势」。
- 手机灯箱：全屏，一屏放下一套——标题、大图、五机位缩略条、底栏（上一套 / 下一套 / 详情 / 下载）；
  四语名称、英文描述、复制 ID、分享等收进「详情」，展开后才可滚动。
  手机（`pointer: coarse`）上下载按钮叫「保存到相册」：支持文件分享时调系统分享面板（选「存储图像」进相册），当前机位的 w900 在点之前就预取好，
  因为 iOS 要求 share() 在点击手势里调用；面板关掉后不弹「已保存」（系统不告诉页面用户选了什么）。不支持（微信等）时在大图底部提示长按保存，
  提示不挡长按。桌面仍是 `<a download>`。
- 语言菜单：点开列出 中文 / 日本語 / English / 한국어，当前语言打勾；选中即跳到该语言的页面（保留筛选参数和 hash，去掉 `?lang`），
  选择记在 localStorage。不用单个按钮轮换语言：读者看不出下一下会到哪种语言。Esc 或点外面关闭。
- 下载面板（首屏按钮和灯箱「下载图包」打开，2026-10-31 改，方案 A「按内容分组」）：每一行都写清装了什么。
  版本 + 「图片 CC0 · 每张 900 px，做参考足够」；黑色「线稿 · 全部系列 · 推荐」大卡，带格式胶囊（线稿 N、实拍 N）和「大多数人只要这个」；
  描边卡「全部格式 · 一次下完」（五种格式胶囊）；「只要新格式」三格并排：白模 / 深度 / 法线各一个包（深度和法线分开：一般只用一种
  ControlNet，法线体积是深度的两倍）；「只要一个系列（线稿 + 实拍）」两列四格，下面一句实拍只有部分标准姿势有；最后虚线框

## 标签与过滤（v0.2.0）
- 系列：全部 / 全身・标准 / 上半身 / 全身・性感 / 双人，分段按钮在分类上方，带该系列全部套数（性感内容模糊时也照算）；本次构建没有的系列不出按钮。
- 分级：`general` / `suggestive`。suggestive 姿势默认留在网格原位、模糊显示（D-06，2026-10-29 由隐藏改为模糊）：
  - 卡片：图 blur 14px（手机 10px），中间白色圆底的划眼图标 +「点按显示」（手机三列只留图标）。第一下只解开这一套，再点才进灯箱；
    单张解开只在本次访问有效，不记住。逐张视图同理。
  - 开关：系列行右侧「性感内容：模糊 / 显示」，珊瑚色描边 + 拨动开关，`role="switch"`，记在 localStorage，不进 URL；手机上排在系列行最前面。
    关掉时清空本次单张解开的记录。
  - 单张解开到第 2 套时，底部弹出一次「已单独显示 N 套 · 全部显示 ×」。
  - 灯箱：模糊的套大图 blur 28px、机位缩略图一起模糊，中间「性感姿势，已模糊」+「显示这一套」「全部显示」；未解开时下载不可用。
    深链（`#S001-front`）照样打开，进来是模糊的。

  （2026-10-29）：NEW 恰好等于 std 以外的三个系列，与系列标签重复；齐全占四成，区分度低。卡片上的 NEW 角标也一起去掉了：最新版本占 75%，不再是提示。
- 质检：只显示通过的机位。缺的机位不论 `gaps` 是 `missing` 还是 `line` / `structure`，读者看到的都是「正在补画」：
  他们只需要知道会补、现在去哪看，不需要质检术语。实拍缺机位是「暂无实拍」。
  一个机位都没通过的姿势整套不出现。

## 素材库与搭配（2026-11-01：服装上线；同日 v2 六个库）
姿势是锚，服装、道具、家具、动物、场景、光线六个库都挂在姿势上。设计画布：Shisei 服装接入设计（v2 一节）。
- 导航：桌面「姿势 / 素材库 ▾ / 更新日志」，素材库下拉按和姿势的关系分三组：穿戴与手持（服装、道具）、身边（家具、动物）、
  环境（场景、光线），每项缩略图 + 件数。1100px 以下导航链接收起，顶栏多一个菜单按钮；手机上 GitHub 收进菜单。
  菜单是全屏面板：「姿势」大字和四个系列在上，六个库 2×3 宫格在下，再下更新日志、GitHub，底部语言和深色模式。
  下拉和菜单都由 `common.js` 根据每页内联的 `window.SHISEI_NAV`（build 生成）画出，图库、库页、静态页同一份。
- 库页 `<lib>/`（每语言一份，`web/library.html` + `library.js`）：标题比首页小一档；大类胶囊（桌面换行、手机横滑）、
  性别（只有服装）、视角（各库自己的视角；动物多一个「主视角」：四足侧面、鸟和龙正面）；手机三列。
  灰底商品照（服装、道具、家具）和照片（场景、光线）铺满 `#D9D9D9`；动物线稿和姿势一样 multiply 在 `--tile` 上。
  性感内衣同姿势一样默认模糊，共用一个开关。托盘里有姿势时，桌面卡片悬停出「配上 P018」。
- 大图：各库视角，← → 视角、↑ ↓ 上一件 / 下一件、Esc；手机名称在顶部，下面大图、视角条、主按钮、下载，英文描述在下方。
