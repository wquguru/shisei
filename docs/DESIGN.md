# 画廊设计

给 agent 实现 `web/` 用的文字版。视觉稿在设计画布（Shisei Pose Gallery，五块画板：桌面、Logo、灯箱、手机、卡片状态），
尺寸、颜色、文案以画布为准，这里只记规则。

## 风格
- 底色 `#F5F2ED` 暖米白，次级面 `#ECE7DF`，描边 `#DCD6CC`；文字 `#18181B` / `#3F3D39` / `#55534E`，最浅的说明文字 `#6B6862`。
- 主按钮黑色胶囊 `#18181B`，次按钮米白描边胶囊；NEW 标签 `#F2F08A` 黄色胶囊。
- 标题 Inter Tight 800，字距 -0.05em，带 3px 4px 的暖色投影 `#EDB79C`；中文 Noto Sans SC；编号和计数 JetBrains Mono。
- 网格卡片统一暖灰底 `#ECE7DF`；悬停或聚焦时底色过渡成该分类色、上浮 3px 并加阴影（0.25s）。手机没有悬停，保持暖灰。
- 首屏滚动方块始终用分类色。线稿用 `mix-blend-mode: multiply` 叠上去，白底自动变成底色。分类色：
  坐姿 `#D3D1E6` 站立 `#AFC3E0` 跪姿 `#BCD3C6` 躺姿 `#E3CBB0` 侧坐 `#EBC0BC` 蹲姿 `#C7DCD6` 前倾 `#E6B7A1` 后仰 `#CBD0AC` 扭转 `#DDB9C8`；
  实拍统一 `#E4E1DC`。
- 卡片圆角 28px（手机 22px），灯箱外框 34px。

## 页面结构（桌面）
1. 导航：logo 胶囊、姿势 / 分类 ▾ / 机位 ▾ / 实拍 / 使用方法 / 更新日志，右侧语言菜单（地球图标 + 当前语言名 ▾）、深色模式、GitHub。不做搜索（2026-10-29 去掉）。
2. 首屏：大标题、一句说明、两行反向滚动的姿势方块（尊重 `prefers-reduced-motion`）、各系列套数胶囊、「浏览 N 套姿势」「下载图包 [大小]」、适用工具。
   N 是全部已发布的套数（有通过质检的机位），不随性感内容开关变化；没有写死的数字。
3. 全部姿势：吸顶筛选条（分类胶囊带色点和数量、机位、线稿/实拍、按姿势/逐张、计数），下面是网格。
4. 页脚：只写一句「全部素材由 Shisei 自制。」加链接，不提其他项目。

## 交互
- 姿势卡：默认正面；悬停、聚焦或点按圆点切换本卡机位；顶栏选机位时全部卡片统一切换。
- 缺机位（2026-10-29 改）：圆点变空心并禁用。主图位置不画虚线框，放一个图标（线稿铅笔、实拍相机）、一句短话和一个出口：
  卡片上是「看<最近的有图机位>」（同一素材内，素材切换是全页的）；手机三列只留图标和「补画中 / 无实拍」。
  灯箱缺图时先给另一种素材的同机位（「看线稿」/「看实拍」），再给最近机位；对比里缺的一边只有图标和标题。
- 实拍模式只列有实拍的 23 套；某机位无实拍时同样按缺机位处理（P050 只有正面）。
- 逐张视图：每个机位一张小卡，受分类和机位筛选影响。
- 灯箱：左边大图，右边四语名称、机位缩略图、线稿/实拍切换、可复制的 `desc_en`、下载 900 图、复制 ID、全尺寸包链接。
  键盘 ← → 换机位、↑ ↓ 换姿势、L 在线稿 / 实拍 / 对比之间轮换、Esc 关闭；手机左右滑动。
- 对比模式（2026-10-29）：只在灯箱和姿势页，网格仍是线稿 / 实拍两种（对比要一张大图的空间，且只有 std 的实拍套有内容）。
  线稿 3:4 和实拍 1:2 同高并排（3fr 2fr），放在中性底 `--tile` 上，线稿 multiply；不做叠图或滑杆，两者取景不同、对不齐。
  缺一边用缺机位提示（图标 + 标题）；两边都有的机位缩略图右上角一个珊瑚色小点；下载换成「线稿 900」「实拍 900」两个。
  整套没有实拍时「对比」和「实拍」一起禁用；↑ ↓ 翻到这样的套自动落回线稿。深链 `#P001-diag-compare`。
  姿势页在五个机位下面加「线稿与实拍对照」一节，只列两边都有的机位，点图进灯箱对比。
- 手机：默认三列网格（只留 ID + 名称一行、不显示圆点），右侧按钮切回两列，选择记在 localStorage。没有筛选面板（2026-10-29 去掉）：
  吸顶条里系列行随页面滚走，分类胶囊和机位 / 素材 / 视图开关留在顶部，各行横滑不换行。
- 手机首屏：连导航一屏放下（标题 32px、滚动方块只留一行、胶囊缩小），首屏底部露出「全部姿势」。
- 手机灯箱：全屏，一屏放下一套——标题、大图、五机位缩略条、底栏（上一套 / 下一套 / 详情 / 下载）；
  四语名称、英文描述、复制 ID、分享等收进「详情」，展开后才可滚动。
- 语言菜单：点开列出 中文 / 日本語 / English / 한국어，当前语言打勾；选中即跳到该语言的页面（保留筛选参数和 hash，去掉 `?lang`），
  选择记在 localStorage。不用单个按钮轮换语言：读者看不出下一下会到哪种语言。Esc 或点外面关闭。
- 下载面板（首屏按钮和灯箱「下载图包」打开）：版本 + 许可证、一句说明（轻量包画质几乎无差别，体积约为原图的 1/k，k 按实际大小算）、
  黑色「全部系列 · 推荐」大卡（黄色大小标签）、「只要一个系列」四行、分隔线下虚线框的「原图包」。只标 MB，不标像素尺寸。
  大小、套数来自 `data/packs.json`（`tools/pack_release.py` 生成），链接指向该版本的 Release 附件。
- 所有可点元素至少 44px，图标按钮带 `aria-label`。

## 标签与过滤（v0.2.0）
- 系列：全部 / 全身・标准 / 上半身 / 全身・性感 / 双人，分段按钮在分类上方，带当前可见套数；没有可见姿势的系列不出按钮。
- 分级：`general` / `suggestive`。右上「性感内容：隐藏 / 显示」开关，默认隐藏（D-06），记在 localStorage，不进 URL。
- 分类：选了系列才出该系列的分类（颜色按 `class_en`），另有 NEW（最新 `added_in`，全系列都新时不显示）和「五机位齐全」。
- 质检：只显示通过的机位。缺的机位不论 `gaps` 是 `missing` 还是 `line` / `structure`，读者看到的都是「正在补画」：
  他们只需要知道会补、现在去哪看，不需要质检术语。实拍缺机位是「暂无实拍」。
  一个机位都没通过的姿势整套不出现。
- URL：`?series=upper&cat=0&full=1`；深链 `#S001-front` / `#U017-side` / `#D001-front` 同样可用（被分级挡住的不打开）。

## 静态页与分享（tools/site_pages.py 生成）
- 每个语言一份：zh 在根目录（也是 x-default），ja / en / ko 在子目录；页面都是目录（`pose/P001/`），链接全部相对，子路径部署可用。
- zh 页面在首帧前按「?lang → 已保存的语言 → 浏览器语言」跳到对应语言；爬虫不跳，各语言 URL 各自被收录。其他语言页只认 ?lang。
- 姿势页：面包屑、ID · 分类 · 机位数、名称（大标题）+ 其他三种语言名、「在画廊中打开」「分享」、可复制的 `desc_en`、
  五个机位大图（各带 900 下载，缺机位是铅笔图标 +「正在补画」）、上一套 / 下一套、同类姿势（最多 8 个）。
- 更新日志：月份分组、按类型筛选（无 JS 时全部显示）、Atom 订阅、分享。文案写给读者：现在能看到什么，不写实现。
- 分享：手机走系统分享面板；桌面弹出面板，复制链接 + 按语言给的平台（zh 微博、ja / ko LINE、en Reddit，都有 X、Pinterest、Facebook）。
  不加载任何 SDK。分享的永远是姿势页 URL（它有自己的分享卡），不分享 `#P001` 这种 hash。
- 分享卡 1200×630：左边 logo、ID · 分类、名称、机位数黄胶囊 + 机位名；右边正面大图 + 两个小机位，分类色底、线稿 multiply。
  首页卡：大字 Shisei（带暖色投影）、「N 套 × 5 机位」、六个彩色方块。只用线稿。
