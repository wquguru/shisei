# 画廊设计

给 agent 实现 `web/` 用的文字版。视觉稿在设计画布（Shisei Pose Gallery，五块画板：桌面、Logo、灯箱、手机、卡片状态），
尺寸、颜色、文案以画布为准，这里只记规则。

## 风格
- 底色 `#F5F2ED` 暖米白，次级面 `#ECE7DF`，描边 `#DCD6CC`；文字 `#18181B` / `#3F3D39` / `#55534E`，最浅的说明文字 `#6B6862`。
- 主按钮黑色胶囊 `#18181B`，次按钮米白描边胶囊；NEW 标签 `#F2F08A` 黄色胶囊。
- 标题 Inter Tight 800，字距 -0.05em，带 3px 4px 的暖色投影 `#EDB79C`；中文 Noto Sans SC；编号和计数 JetBrains Mono。
- 网格卡片统一暖灰底 `#ECE7DF`；悬停或聚焦时底色过渡成该分类色、上浮 3px 并加阴影（0.25s）。手机没有悬停，保持暖灰。
- 首屏滚动方块和「新增 23 套」横排始终用分类色。线稿用 `mix-blend-mode: multiply` 叠上去，白底自动变成底色。分类色：
  坐姿 `#D3D1E6` 站立 `#AFC3E0` 跪姿 `#BCD3C6` 躺姿 `#E3CBB0` 侧坐 `#EBC0BC` 蹲姿 `#C7DCD6` 前倾 `#E6B7A1` 后仰 `#CBD0AC` 扭转 `#DDB9C8`；
  实拍统一 `#E4E1DC`。
- 卡片圆角 28px（手机 22px），灯箱外框 34px。

## 页面结构（桌面）
1. 导航：logo 胶囊、姿势 / 分类 ▾ / 机位 ▾ / 实拍 / 使用方法 / 更新日志，右侧搜索胶囊、语言、深色模式、GitHub。
2. 首屏：大标题、一句说明、两行反向滚动的姿势方块（尊重 `prefers-reduced-motion`）、「浏览 73 套姿势」「下载全尺寸原图包」、适用工具。
3. 新增 23 套：横向滚动卡片，带 NEW。
4. 全部姿势：吸顶筛选条（分类胶囊带色点和数量、机位、线稿/实拍、按姿势/逐张、计数），下面是网格。
5. 页脚：只写一句「全部素材由 Shisei 自制。」加链接，不提其他项目。

## 交互
- 姿势卡：默认正面；悬停、聚焦或点按圆点切换本卡机位；顶栏选机位时全部卡片统一切换。
- 缺机位：圆点变虚线并禁用，主图位置写明原因（P062 仰视）。
- 实拍模式只列有实拍的 23 套；某机位无实拍时同样按缺机位处理（P050 只有正面）。
- 逐张视图：每个机位一张小卡，受分类和机位筛选影响。
- 灯箱：左边大图，右边四语名称、机位缩略图、线稿/实拍切换、可复制的 `desc_en`、下载 900 图、复制 ID、全尺寸包链接。
  键盘 ← → 换机位、↑ ↓ 换姿势、L 切素材、Esc 关闭；手机左右滑动。
- 手机：两列网格，分类横滑，筛选收进底部面板（机位、素材、视图、重置、显示 N 套）。
- 语言切换覆盖全部界面文案和姿势名，记在 URL 参数和 localStorage。
- 所有可点元素至少 44px，图标按钮带 `aria-label`。

## Logo
定稿用 A 动势线（2026-10-28）：`#18181B` 圆角方块（rx 24/100），米白头部圆环，珊瑚色 `#E07A52` 动势弧线。24px 以下去掉头部圆环、只留弧线。其余四个方向留在画布上作存档。
